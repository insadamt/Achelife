## Summary

Achelife 1.0.0 is the first stable v1 release.

## What's New

**Daily planning:** Today, Tasks, recurring routines, Habits, and streaks.

**Seasons:** 30-day Seasons, Objectives, Rank, and end-of-Season reviews.

**Personal records:** Diary, People, Constitution, and Money tracking.

**Setup and recovery:** Resumable setup, portable account exports, full-instance backups, and failed-update recovery.

Free and open-source under the MIT License.

## Install

Requires Linux, Docker Engine, Docker Compose v2, `curl`, `tar`, and a SHA-256 utility.

```bash
curl -fsSL https://raw.githubusercontent.com/insadamt/Achelife/v1.0.0/scripts/install.sh | sh
```

Open **http://127.0.0.1:8080** to complete setup.

**Privacy:** Achelife has no login. Anyone who can reach it can access all data. Keep it on localhost, a trusted private network, or a private VPN.

## Update

```bash
achelife backup
```

Copy the backup outside the Docker host, then run:

```bash
achelife update --to 1.0.0
achelife doctor
```

## Known Issues

**Web dependencies:** The September 5 scan reported 16 fixable HIGH findings per architecture in curl/libcurl `8.20.0-r0` (fixed in `8.22.0-r0`), and no fixable CRITICAL findings. App images had no fixable HIGH or CRITICAL findings.

**Subscription preview:** A monthly Subscription starting today can preview next month. Saving correctly creates a payment due today.

**Restore testing:** Clean-install restore passed on the same host. The maintainer approved release after reinstall recovery; a separate-machine restore remains unverified.
