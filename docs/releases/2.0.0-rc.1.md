# Achelife v2.0.0-rc.1 release report

Prepared on 6 October 2026 from `codex/v1.4.0`. The owner explicitly requested public publication after initially requesting an internal test candidate. This RC remains a pre-release; stable promotion and manual acceptance are separate steps.

## Candidate changes

The [release notes](../../scripts/release/changes/2.0.0.md) describe the implemented design, navigation, appearance, Money People, statistics, and portability changes. The roadmap still contains unfinished phases and manual review gates. This RC does not claim complete roadmap acceptance or a third Normal glass style/full semantic-palette editor.

Release preparation fixes GSAP cleanup callback types, nullable navigation values, React chart ref updates during render, PHP formatting, and the source line-count gate incorrectly counting binary images and local SQLite data. Locked security updates are limited to Laravel, CommonMark, Flysystem, two existing brace-expansion dependency copies, and source-map-js. No new feature library or release framework was introduced; the existing guarded release workflows handle publication.

## Validation and limitations

- PHP: 465 tests passed, 3,544 assertions, including legacy archive and migration compatibility coverage.
- Composer and npm audits: zero advisories after targeted lockfile updates.
- Pint, TypeScript, ESLint, release note regression tests, and installer/manager shell tests pass.
- Local Docker acceptance could not start its build because Docker Buildx is absent. The GitHub release workflow installs Buildx and must pass isolated Docker acceptance, source verification, and amd64/arm64 app/web image scans before publication.
- Manual browser acceptance and full desktop/mobile visual review remain pending.
- Installed Docker instances, including Achelife on port 8081, were not updated or recreated.

## Manual test checklist

Use a separate disposable installation and retain a verified backup outside the Docker host before testing upgrades or restore.

- [ ] Fresh install, setup, onboarding, restart, and diagnostics.
- [ ] Light/Dark × Normal/Frosted glass; separate main colors, custom background upload/removal, and reload persistence.
- [ ] Desktop/mobile navigation, keyboard focus, 320px layout, large text, and reduced motion.
- [ ] Today task completion/undo and boolean/numeric Habit completion; check animation cancellation and popup positioning.
- [ ] Tasks Files/Archived, Calendar drawer, Focus start/pause/switch/finish, and animated statistics/chart updates.
- [ ] Seasons, objectives, closeout/intermission, Diary, Constitution, and historical statistics.
- [ ] Money income/expense People picker, subcategory search, History filters, totals, transfer, debt repayment, and subscription.
- [ ] Upgrade a copy of an older supported account and compare data/settings.
- [ ] Restore old archives, round-trip format 12, and export an account with a zero-day historical intermission.
- [ ] Full-instance backup, off-host copy, clean-host restore, failed-update recovery, and restart persistence.
- [ ] Review scan findings and known roadmap gaps before accepting the RC.
