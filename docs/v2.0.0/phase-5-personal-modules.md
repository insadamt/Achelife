# Phase 5 — Seasons and personal modules

**Status:** Not started. [Roadmap](../v2.0.0_design_plan.md) · [UI guide](../ui-design-and-motion.md) · [Layout guide](../ui-layout-and-hierarchy.md)

## Plan

Apply one design language to Seasons, Rank, Habits, Diary/People, and Constitution. Preserve the [user guide](../user-guide.md) workflows and the definitions in [Season statistics](../season-statistics.md) and [Habit statistics](../habit-statistics.md). A larger Season hero is allowed only as a documented exception.

## Implementation tasks

- [ ] Redesign Season introduction, command center, objective board, statistics, Rank guide, closeout, and intermission using shared roles.
- [ ] Redesign Habits active/archive views, check-in controls, calendar, editors, and statistics with readable progress and status cues.
- [ ] Redesign Diary calendar/editor, mood selection, People presentation, autosave/error feedback, and long-form reading surfaces.
- [ ] Redesign Constitution active/archive views, Law cards/details/editors, and violation confirmation and history.
- [ ] Preserve Season attribution, objective and Rank calculations, Habit schedules/streaks/skips, Diary autosave, and Law penalties.
- [ ] Record hero, dense-data, or reading-width exceptions with reasons.

## Manual review checklist

- [ ] User checks current/historical Season, objectives, statistics, Rank, closeout, and intermission states.
- [ ] User checks Habit create/edit/check-in/skip/archive and statistics, including numeric and Boolean Habits.
- [ ] User checks Diary autosave and mood/People interactions, plus Constitution create/edit/violation/archive actions.
- [ ] User reviews long text, empty and archived states, keyboard focus, and status meaning without color or animation.

## Exit and handoff

Exit when every listed route and its state is accepted. Follow the [common review matrix](../v2.0.0_design_plan.md#common-manual-review-for-each-visual-phase).
