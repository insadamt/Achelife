# Achelife

Achelife V2 is being built progressively from a deliberately small Laravel and React foundation.

Phase 0 provides the framework, authentication, local SQLite database, and quality checks. Phase 0.5 adds the global visual system, reusable interface primitives, responsive authenticated shell, and authentication presentation. Phase 1 adds automatic 30-day Seasons, historical synchronization, Season introductions, and the Seasons carousel.

See the [Phase 0 foundation guide](docs/phase-0-foundation.md) for setup, the [Phase 0.5 global UI foundation](docs/phase-0.5-global-ui-foundation.md) for the interface architecture, and the [Phase 1 Seasons guide](docs/phase-1-seasons.md) for the Season domain and lifecycle.
