# Achelife

Achelife V2 is being built progressively from a deliberately small Laravel and React foundation.

Phase 0 provides the framework, authentication, local SQLite database, and quality checks. Phase 0.5 adds the global visual system, reusable interface primitives, responsive authenticated shell, and authentication presentation. No Achelife domain modules are implemented yet.

See the [Phase 0 foundation guide](docs/phase-0-foundation.md) for setup and the [Phase 0.5 global UI foundation](docs/phase-0.5-global-ui-foundation.md) for the interface architecture and verification scope.
