# Achelife

Achelife V2 is being built progressively from a deliberately small Laravel and React foundation.

Phase 0 provides the framework, authentication, local SQLite database, and quality checks. Phase 0.5 adds the global visual system and application shell. Phase 1 adds automatic 30-day Seasons and Season introductions. Phase 2 adds global Tasks, recurrence, subtasks, dynamic rewards, and historically safe Season SP attribution.

See the [Phase 0 foundation guide](docs/phase-0-foundation.md) for setup, the [Phase 0.5 global UI foundation](docs/phase-0.5-global-ui-foundation.md) for the interface architecture, the [Phase 1 Seasons guide](docs/phase-1-seasons.md) for the Season lifecycle, and the [Phase 2 Tasks guide](docs/phase-2-tasks.md) for Tasks, recurrence, and reward attribution.
