# Achelife

Achelife V2 is being built progressively from a deliberately small Laravel and React foundation.

Phase 0 provides the framework, authentication, local SQLite database, and quality checks. Phase 0.5 adds the global visual system and application shell. Phase 1 adds automatic 30-day Seasons and Season introductions. Phase 2 adds global Tasks, recurrence, subtasks, dynamic rewards, and historically safe Season SP attribution. Phase 3 adds effective-dated Habits and streak progression. Phase 4 adds the autosaved Diary, People, moods, and writing rewards. Phase 5 adds global Laws and escalating, Season-safe Constitution violations. Phase 6 adds non-gamified Money tracking. Phase 7 adds Boolean Objectives inside each Season with setup locking and exact reward rebalancing.

See the [Phase 0 foundation guide](docs/phase-0-foundation.md) for setup, the [Phase 0.5 global UI foundation](docs/phase-0.5-global-ui-foundation.md) for the interface architecture, the [Phase 1 Seasons guide](docs/phase-1-seasons.md) for the Season lifecycle, the [Phase 2 Tasks guide](docs/phase-2-tasks.md) for Tasks, recurrence, and reward attribution, the [Phase 3 Habits guide](docs/phase-3-habits.md), the [Phase 4 Diary guide](docs/phase-4-diary.md), the [Phase 5 Constitution guide](docs/phase-5-constitution.md), the [Phase 6 Money guide](docs/phase-6-money.md), and the [Phase 7 Season Objectives guide](docs/phase-7-season-objectives.md).
