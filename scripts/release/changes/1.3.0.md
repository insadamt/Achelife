# Achelife v1.3.0

Achelife v1.3.0 is a major Tasks update focused on organization, planning, and Focus Time, with additional improvements to Money, Settings, and branding.

## Added

* Added **Folders, Projects, and Inbox** for organizing Tasks in a file-explorer-style workspace.
* Added Folder and Project colors, archiving, restoration, drag-and-drop movement, and ordering.
* Added a **Task Calendar** with Month, Week, and Three-day views, Project filters, and drag-and-drop rescheduling.
* Added **Focus Time** with a persistent timer, pause/resume controls, Task switching, and a global Dynamic Island.
* Added Focus history, manual time entry, editing, and deletion.
* Added Focus statistics including totals, averages, heatmaps, Project breakdowns, and most-focused Tasks.
* Added Task notes, improved Task details, search, and filtering.

## Changed

* Redesigned Task and Focus editing with a unified details drawer.
* Redesigned Subtask editing and removed the previous checklist limit.
* Improved recurring Task edits while preserving past occurrences.
* Added colors and improved breakdowns to Money statistics.
* Added Debt insights and Account balance reconciliation.
* Redesigned General Settings into clearer Appearance, Profile, Calendar, Season, and Account Data sections.
* Added the new Achelife logo with automatic light and dark variants.

## Fixed

* Fixed Dynamic Island outside-click and mobile dismissal behavior.
* Improved Focus controls for running and paused Tasks.
* Improved validation and safety around Task organization, Focus Sessions, and account portability.

## Data & Compatibility

* Account exports now use **archive format v9**.
* Restore compatibility is preserved for **formats v1 through v8**.
* Existing Tasks, Focus data, Money history, Seasons, SP, and completion history remain compatible.

Focus Time remains informational and does not affect SP, Rank, Seasons, or Daily Progress.
