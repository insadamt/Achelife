Achelife v1.3.0 improves Tasks with organization, Focus Time, and expanded statistics.

## Added

- Added Folders, Projects, and an Inbox for organizing Tasks in a file-explorer workspace.
- Added Task notes, search, filters, accessible movement controls, and ordering within each location.
- Added Focus Time with a persistent global timer, pause and resume controls, completed-session history, and manual corrections.
- Added Focus metrics, activity charts, a daily heatmap, Project and Inbox totals, and most-focused Task rankings.
- Added one-action Focus switching between Tasks with a single running counter, paused Task controls, and Task search in the Dynamic Island.

## Changed

- Improved Task and Focus editing with a unified details drawer and a redesigned Subtask checklist.
- Improved recurring Task edits so Project and note changes apply from the selected occurrence forward while past occurrences remain unchanged.
- Advanced portable account archives to format version 6 while preserving explicit imports for formats 1 through 5.
- Kept Focus Time informational so it does not affect Task rewards, Season SP, Rank, or Daily Progress.
