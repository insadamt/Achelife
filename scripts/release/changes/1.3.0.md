# Achelife v1.3.0

Achelife v1.3.0 transforms Tasks into a complete planning and Focus workspace, while also refining Money statistics, Settings, and Achelife's visual identity.

## What's New

### Tasks 2.0

Tasks now use a file-style organization system built around **Folders → Projects → Tasks**, with **Inbox** remaining the home for unassigned Tasks.

- Added Folders and Projects with visual file-explorer navigation.
- Added root Projects and Inbox alongside Folder-based organization.
- Added drag-and-drop movement for Projects and Tasks.
- Added accessible Move controls for precise movement without drag-and-drop.
- Added manual ordering within Task locations.
- Added colors for Folders and Projects, with distinct saved colors for Projects.
- Added Folder and Project archiving without deleting their Tasks.
- Added Archived Files with restoration support.
- Deleting a Folder now moves its Projects back to Files root.
- Deleting a Project now safely moves its Tasks back to Inbox.
- Added Task notes and richer Task details, including Project context, recurrence, subtasks, rewards, and rescheduling history.
- Added Task search and filtering support across titles, notes, Projects, completion state, and importance.

### Task Planning Calendar

Added a dedicated **Tasks → Calendar** workspace for planning scheduled Tasks across Projects and Inbox.

- Added **Month**, **Week**, and rolling **Three-day** calendar views.
- Added Project and Inbox filtering.
- Added focused daily agendas.
- Added drag-and-drop Task rescheduling between dates.
- Added direct access to Task details from the calendar.
- Project colors are carried throughout the planner for faster visual identification.

### Focus Time

Tasks now include built-in Focus Time tracking.

- Added a persistent server-backed Focus timer.
- The timer continues accurately across navigation, reloads, and closed browser tabs.
- Added start, pause, resume, and finish controls.
- Added a global **Dynamic Island** for controlling Focus from anywhere in Achelife.
- Added one-action switching between Tasks: the running Task is paused and the selected Task starts or resumes.
- Multiple Tasks may remain paused while only one counter runs at a time.
- Added Task search directly inside the Dynamic Island for quickly switching Focus.
- Running Tasks can be finished directly from their Task controls.
- Completing a Task automatically finishes its open Focus Session.
- Added animated Dynamic Island transitions with reduced-motion support.

### Focus History & Manual Time

- Added completed Focus Session history inside Task details.
- Added manual Focus Time entry.
- Added editing and deletion of completed Focus Sessions.
- Timer sessions preserve their actual pause gaps.
- Manual and corrected Focus ranges are protected against overlapping existing Focus intervals.
- Focus history is displayed using the profile's configured timezone.

### Focus Statistics

Task Statistics now include detailed Focus analytics alongside the existing completion statistics.

- Added Total Focus Time.
- Added completed Focus Session count.
- Added Average Session.
- Added Average Focus per Active Day.
- Added Longest Session.
- Added Focus activity charts.
- Added a daily Focus heatmap.
- Added Focus breakdown by Project and Inbox.
- Added most-focused Task rankings.
- Added previous-period comparisons for supported Season, Month, and Year views.
- Focus duration is correctly split across local days, months, years, and Season boundaries.

Focus Time remains informational and **does not affect SP, Rank, Task rewards, Seasons, or Daily Progress**.

## Task Experience Improvements

- Redesigned the Subtask editor and removed the previous fixed checklist limit.
- Multiple checklist items can now be pasted at once.
- Unified Task and Focus editing inside the Task details drawer.
- Desktop Task editing now expands into a split workspace instead of stacking additional dialogs.
- Mobile editing retains a compact drawer flow.
- Recurring Task Project and note changes now apply from the selected occurrence forward while preserving past occurrences.
- Improved Project and Inbox scoped Today, Upcoming, Overdue, and Completed views.

## Money Improvements

### Category Colors

- Added persistent colors to Money Categories.
- Category colors now follow Categories through transaction entry, Money activity, Subscriptions, History, and Statistics.
- Subcategories inherit their parent Category color.

### Statistics

- Redesigned the Money distribution experience around an interactive donut chart.
- Added clearer Spending by Category and Income-source breakdowns.
- Added detailed Debt statistics including outstanding payable, receivable, overdue amounts, borrowing, lending, repayments, collections, and forgiveness.
- Added historical Account balance reconciliation showing period opening balance, activity, and closing balance.
- Historical Account statistics now reconcile against the selected period instead of presenting today's balance.
- Improved Income, Spending, Net Cash Flow, Savings Rate, Subscription, fee, and supporting financial insights.

## Settings Redesign

General Settings has been reorganized into clearer sections for:

- Appearance
- Profile
- Calendar
- Season
- Account data

Additional improvements include:

- Improved timezone configuration with current local-time previews.
- Added browser timezone detection for faster setup.
- Improved warnings when a timezone change would alter the current calendar day.
- Improved save-state feedback throughout Settings.
- Redesigned account export and restore controls.
- Made the two-step archive replacement process clearer and safer, including validation before replacement and explicit `RESTORE` confirmation.

## Branding

- Replaced the previous placeholder Achelife mark with the new Achelife logo.
- Added separate light and dark logo assets.
- Achelife now automatically uses the white logo in dark mode and the black logo in light mode.

## Fixed

- Fixed the Dynamic Island remaining open after clicking outside it.
- Improved mobile Dynamic Island dismissal so interacting with its trigger no longer causes incorrect close behavior.
- Improved Focus controls so running Tasks expose a direct Finish action while paused Tasks remain resumable.
- Hardened Folder, Project, Task, Focus, and portability operations against invalid ownership, stale ordering, conflicting Focus intervals, and inconsistent archive data.

## Data & Compatibility

- Added additive database migrations for Task organization, Focus Sessions and intervals, Focus switching, Folder and Project archive state, Task location colors, and Money Category colors.
- Account portability now includes Task organization, Focus data, archive state, Task location colors, and Money Category colors.
- Advanced the portable account archive format to **version 9**.
- Explicit restore compatibility is preserved for **archive formats 1 through 8**.
- Older installations upgrade with existing Tasks placed safely into Inbox where newer organization data did not previously exist.
- Existing completion history, recurrence, SP, Season attribution, Money history, and other persisted data remain compatible.
