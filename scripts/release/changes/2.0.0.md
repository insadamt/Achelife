Achelife v2.0.0 improves the app design, appearance, navigation, statistics, and Money tracking.

## Added

- Added separate Light and Dark main colors, custom backgrounds, and selectable Frosted glass appearance.
- Added optional People on Money income and expenses, History filters, and per-person totals.
- Added animated navigation, task and Habit completion feedback, and chart transitions with reduced-motion support.

## Changed

- Improved the app shell, sidebar, Today, page widths, shared controls, and Light/Dark contrast.
- Improved Tasks navigation, archived views, Calendar agenda drawers, and task composer interactions.
- Improved statistics comparisons with compact delta badges and expandable details.
- Updated existing PHP and npm dependencies to address dependency security advisories.
- Account exports use format 12 while retaining import support for formats 1 through 11.

## Fixed

- Fixed account exports and restores for valid zero-day historical intermissions.
- Fixed background uploads, Calendar background gaps, popup positioning, and missed frosted surfaces.
- Fixed animation cleanup types, navigation nullability checks, and chart ref updates during React rendering.
