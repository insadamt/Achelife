Achelife v1.2.0 improves Money organization, transaction details, and reusable financial labels.

## What's New

## Added

- Added reusable Merchants to show where income came from or where spending went.
- Added colored Tags for dimensions that cross Categories, such as Xbox, Retro, or Physical.
- Added Merchant and Tag filters and search support in Money History.
- Added complete Merchant and Tag lifecycle controls, including creation, editing, archiving, reactivation, and safe deletion of unused values.

## Changed

- Unified Categories, Merchants, and Tags in the new Money Organization workspace.
- Improved transaction entry with a searchable visual Merchant picker that follows the Category selection pattern.
- Preserved archived Merchants and Tags in historical transactions while excluding them from new activity until reactivated.
- Advanced portable account archives to format version 3 while preserving format versions 1 and 2 imports.
